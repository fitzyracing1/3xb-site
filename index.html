How it works

1. Crawl

Public web pages are crawled and stored continuously.

2. Extract

Entities are tagged (Organization, Product, Location, FinancialFigure…) and weighted by frequency and recency.

3. Connect

Co-occurrence builds a relationship graph — see it in the graph explorer.

4. Signal

/entity/{name}/loan-score blends an organization's own weight with its neighborhood into a composite web signal for your underwriting workflow.

Endpoints: /stats /entities /entity/{name} /entity/{name}/loan-score /search?q= /tags /tag/{tag} /graph /export (CSV) — full reference in the API docs.
